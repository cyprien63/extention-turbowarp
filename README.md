# Extension TurboWarp

Une collection d'extensions pour TurboWarp.

## Extensions disponibles

- [Calcul](./calcul) : Extension pour les calculs mathématiques avancés.
- [IA](./IA) : Intégration de diverses IA (ChatGPT, Gemini, Groq, etc.).
- [Serveur Local](./serveur-local) : Outils pour la communication avec un serveur local.
- [Voice Enregistreur](./voice-enregistreur) : Enregistrement vocal.
