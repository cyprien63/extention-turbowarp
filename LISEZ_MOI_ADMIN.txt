--- ACCÈS ADMINISTRATEUR (PRIVÉ) ---

Voici comment accéder aux statistiques de votre site :

1. LIEN PUBLIC : https://votre-pseudo.github.io/extention-turbowarp/
2. LIEN ADMIN (Stats) : https://votre-pseudo.github.io/extention-turbowarp/?stats

--- FONCTIONNEMENT TECHNIQUE ---

Le site étant statique (GitHub Pages), il ne possède pas de base de données. 
Le compteur fonctionne grâce à un "Pixel de suivi" (via le service HITS) :

1. Chaque fois qu'une page se charge, le script crée une image invisible.
2. Le navigateur demande cette image au serveur de HITS.
3. Le serveur de HITS reçoit la requête, enregistre l'adresse IP (pour éviter de compter 100 fois la même personne) et incrémente un compteur dans SA base de données.
4. Le script n'affiche l'image (le badge) que si vous ajoutez "?stats" dans l'URL.

C'est la méthode la plus légère et efficace pour un site sans serveur.
